# IXAK

Маленькая офлайн-утилита для macOS: диагностика железа, здоровье батареи и безопасная чистка кэшей.

Сделано [ihorsyv](https://github.com/ihorsyv) исключительно для личного использования — не распространяется и не поддерживается как продукт.

## Что делает

- **Diagnostics** — нагрузочный тест CPU (все ядра), тест RAM (запись + верификация), тест скорости диска
- **Battery** — износ, циклы заряда, температура — напрямую из системных сервисов IOKit
- **Cleanup** — сканирует кэши приложений, логи, DerivedData, iOS DeviceSupport; удаляет только в Корзину, с подтверждением
- **About** — версия, коммит сборки, ручная проверка обновлений (по кнопке, не в фоне)

Работает полностью офлайн: сеть используется только по явному нажатию "Check for Updates".

## Установка

Собрать самому (нужен Xcode):

```bash
git clone https://github.com/ihorsyv/ixak.git
cd ixak/ixak-mac-utility
./Scripts/build_app.sh release --universal
open build/IXAK.app
```

Либо собрать готовый инсталлятор для передачи на другой Mac:

```bash
./Scripts/build_installer.sh
```

Появится `build/IXAK Installer.app` — при запуске спросит папку установки, добавит ярлык на рабочий стол и удалит сам себя.

Приложение не подписано сертификатом Apple Developer (только ad-hoc), поэтому macOS покажет предупреждение Gatekeeper при первом запуске: правый клик по файлу → «Открыть», либо Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно».

### Если инсталлятор вообще не открывается

Если файл пришёл через Telegram (или другой мессенджер), могло наложиться сразу несколько ограничений: карантин от Telegram, «сэндбокс»-флаг у распакованного файла, потерянный бит запуска после распаковки zip — и в довесок Gatekeeper всё равно ругается на отсутствие подписи Apple. Правый клик → «Открыть» это не всегда чинит. Самый надёжный способ — Terminal:

```bash
cd ~/Downloads   # или туда, куда скачался файл
xattr -cr "IXAK Installer.app"
chmod +x "IXAK Installer.app/Contents/MacOS"/*
codesign --force --deep -s - "IXAK Installer.app"
open "IXAK Installer.app"
```

Начиная с этой версии сам `build_installer.sh` уже переподписывает и `IXAK.app`, и `IXAK Installer.app` после сборки, а сам инсталлятор при установке заново выставляет бит запуска и подпись на копию `IXAK.app` — так что подобные баги внутри уже установленного приложения будут возникать реже. Но карантин и отсутствие Apple-подписи на самом файле инсталлятора, который ещё не запускался, ничем, кроме команды выше, не лечится — это не баг IXAK, а поведение Gatekeeper для любого неподписанного файла из интернета/мессенджера.

## Требования

macOS 13+, Intel или Apple Silicon (собирается как universal-бинарник).
